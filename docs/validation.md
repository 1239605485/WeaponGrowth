# 验证与限制

主机七组测试：成长规则；调度/来源/索引；账本抽奖；中文命令；Hook 生命周期；真实声明驱动的游戏场景；聊天消费/去重。场景验证伤害 5→8、券 10→9、只克隆一次、历史、联网槽位同步、网络切换旧请求清理、召唤和 AI 子弹幕、槽位复用隔离。

构建目标 Android arm64、Windows x86/x64、Linux x86/x64；包工具检查架构、版本、入口与注入指针导出，以及 ZIP 校验。源码交付包含构建脚本、依赖许可、严格夹具与生成器；不包含预编译游戏、原始压缩包、构建缓存或旧文档。

前版 Android 2.0.3 用户确认运行成功。2.1.0 联机和桌面真实游戏未验收；客户端账本不提供服务器认证，原生发送调用不是服务器收包确认。远端重连、服务器插件冲突和多设备联机仍应实测。
