# 2.1.0 架构

loader 管理 KernelLoader 生命周期；engine 缓存反射和适配字段/返回缓冲；hooks 管理逆序卸载；growth 为纯数值规则；catalog 限额构建配方索引；combat 使用固定来源表及可嵌套上下文；storage 提供双槽与迁移；gacha 负责去重池和事务；commands 本地消费中文聊天指令；runtime 连接游戏和网络角色。

合作联机由本地客户端负责，仅对本地来源增加成长与奖励。专用服务端不重复处理。共享鞭子标记仅单人修改。发奖后调用原生 SyncEquipment 槽位同步，不引入自定义报文或服务器账本。

每帧最多一个维护任务，无追赶积压；配方每批 32 条、约 2ms 让出，依赖传播 64 条，库存每批 32 格。伤害和射弹入口不读写文件；普通账本检查点至少 30 秒，发奖事务即时保存。

保留两项关键兼容处理：myPlayer/menu/world/file 使用属性或字段访问器；宿主对小整数返回及 ProjectileKey 的实际复制宽度需要至少八字节缓冲。严格元数据夹具只包含声明，不进入发布动态库。Windows DLL 显式导出入口、日志与 PatchLib 注入指针。
